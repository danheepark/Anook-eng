# 🎬 아눅(Anook) 발표용 시연 시나리오 리스트

발표 및 시연 영상 촬영을 위해 핵심 사용자 경험(UX) 흐름에 따라 구성한 5가지 시나리오입니다. 

---

## 📱 시나리오 1: QR 기반 초고속 체크인 및 채팅방 진입
> **핵심 가치**: 별도 앱 설치나 복잡한 가입 없는 비대면 객실 연결

1. **준비 상황**
   - 모바일 환경 화면 (스마트폰 또는 개발자 도구 모바일 뷰)
   - 사전에 생성된 특정 객실(예: 301호)의 QR 코드 이미지 준비
2. **시연 흐름**
   - [투숙객] 제공된 QR 코드를 모바일 카메라로 스캔
   - [투숙객] 별도 입력 없이 **자동 로그인**이 수행되며 `/guest/chat` 페이지로 즉시 진입
   - [투숙객] "301호 투숙객님 환영합니다!" 웰컴 메시지와 초기 UI 확인

---

## 🤖 시나리오 2: AI 스마트 컨시어지 요청 분류 및 자동화
> **핵심 가치**: 자연어 입력을 통한 AI의 요청 즉시 처리 및 추천

1. **준비 상황**
   - 로그인된 모바일 채팅 화면
2. **시연 흐름**
   - [투숙객] 채팅창에 자연어로 요구사항 입력 
     * *예시 1 (어메니티)*: "방이 좀 추운데 담요랑 수건 2개만 더 가져다주세요."
     * *예시 2 (컨시어지)*: "호텔 근처에 분위기 좋은 일식집 추천해줘."
   - [투숙객] AI가 의도를 분석하여 자동 응답 및 요청 카드 생성 확인
     * 담요/수건 요청 카드가 화면에 자동 생성됨
     * 일식 맛집 추천 리스트가 카드 UI로 깔끔하게 렌더링됨

---

## 🛠️ 시나리오 3: 실시간 직원 태스크 수락 및 진행
> **핵심 가치**: 부서별 실시간 업무 분장 및 처리 투명성 확보

1. **준비 상황**
   - 좌측: 투숙객 모바일 화면 / 우측: PC 스태프 대시보드 화면 멀티스크린 구성
2. **시연 흐름**
   - [투숙객] 수건 추가 요청 발송 (시나리오 2 연계)
   - [직원] 스태프 대시보드에 **실시간 알림(SSE)**과 함께 신규 태스크 카드 등장
   - [직원] '수락' 버튼 클릭 -> 작업 상태가 '진행 중'으로 변경
   - [투숙객] 모바일 화면 내 요청 카드의 상태가 **'처리 중'**으로 실시간 연동되어 변경됨을 노출

---

## 🧹 시나리오 4: 정비 재고 차감 및 자동 정산 (빌링)
> **핵심 가치**: 어메니티 제공과 동시에 이루어지는 자산 관리 및 요금 자동 연동

1. **준비 상황**
   - 스태프 대시보드 내 정비/어메니티 완료 처리 화면
2. **시연 흐름**
   - [직원] 요청 품목 전달 후 '완료' 처리 실행
   - [직원] 백엔드에서 해당 객실의 하우스키핑 재고가 즉시 자동으로 차감 처리됨 확인
   - [투숙객] 최종 정산(빌링) 탭에서 유료 품목이나 추가 요금이 포함된 내역이 **실시간 업데이트**되는 화면 노출

---

## 🚪 시나리오 5: 교대 근무 인수인계 및 체크아웃 세션 만료
> **핵심 가치**: 빈틈없는 직원 간 정보 공유와 체크아웃 즉시 완벽한 권한 회수

1. **준비 상황**
   - PC 스태프 대시보드 및 모바일 투숙객 화면
2. **시연 흐름**
   - [직원] 대시보드 '인수인계(Handover)' 탭에 업무 일지 및 특이사항 작성 후 등록
   - [직원] 퇴실 당일 게스트 '체크아웃' 승인 처리
   - [투숙객] 체크아웃 즉시 **WebSocket을 통해 프론트엔드로 세션 만료 명령이 전송**되어, 투숙객 모바일 화면이 로그아웃되며 로그인 페이지로 자동 리다이렉트됨을 시연
